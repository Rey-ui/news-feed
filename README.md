# News Feed

A responsive news application built with Vanilla JavaScript that allows users to
browse, search, and filter news articles from different countries and
categories.

## 🚀 Live Demo

https://rey-ui.github.io/news-feed/

## Features

- Browse top news headlines
- Search news by keyword
- Filter news by category
- Switch between different countries
- Load more articles with pagination
- Detailed article preview in modal window
- Loading indicators
- Responsive design
- Error handling

## Tech Stack

- JavaScript (ES6+)
- Vite
- Axios
- HTML5
- CSS3
- REST API

## What I Practiced

This project was focused on working with APIs and asynchronous JavaScript.

Key concepts:

- API integration
- Async/Await
- Pagination
- Dynamic rendering
- Filtering and searching
- Modal windows
- Loading states
- Error handling
- Responsive UI development

## ⚙️ Installation

```bash
git clone https://github.com/Rey-ui/news-feed.git

cd news-feed

npm install

npm run dev
```
